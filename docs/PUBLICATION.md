# Public source selection

This independent project was copied into a fresh repository for technical evaluation. The public history begins with this curated snapshot; it does not contain the original private Git objects.

Included: application code, synthetic test fixtures and regression tests, database schema migrations, local Supabase configuration, ingestion algorithms, and generated landing geometry.

Excluded: company PDFs and reference material, commercial context documents, outreach templates, source workbooks, screenshots, personal identifiers in reports, original deployment configuration, environment files, backups, database dumps, private acceptance records and historical Git objects.

Existing migration filenames and module names remain stable to preserve code relationships. Product naming is an independent project label and does not imply affiliation. Public source access is provided for evaluation; no license grant is inferred for this code or for third-party dependencies, which retain their own terms.
